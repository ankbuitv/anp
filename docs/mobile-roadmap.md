# Phase 3 — Mobile (iOS + Android)

Dùng chung `/api/v1`. Không code native trong Phase 1.

## Tính năng

- Camera Upload / Auto Backup (Wi-Fi only, charging only, include videos)
- Background backup + resume + duplicate checksum
- Gallery, album, vault, share, Drop
- LAN transfer + Bluetooth discovery (chỉ pairing) + QR pairing
- Two-way sync, không tự xóa khi conflict

## UX

Bottom nav, fullscreen viewer, swipe, bottom sheet metadata, pull-to-refresh, long-press select, share sheet, camera native.
